# 차트 발굴 탭 — Tech(chart_screener) 리포트를 뷰어에 넣고 보컬을 그 안의 칩으로 (2026-10-09)

사용자 요청: 'Tech 작업물이 127.0.0.1:8765 안에 들어가게, 보컬 탭을 대신하게. 보컬 조건식은 Tech 의 포켓 피벗 옆 단축 버튼으로.'
결정(사용자 답): 탭 이름 '차트 발굴' · 보컬 칩 = 깔때기 ④~⑦(강한 테마 대장주가 큰 상승 뒤 눌림 중) · 예전 보컬 자동 계산 끔.

## 왜 한 프로세스로 합치지 않나
뷰어(서버.py)는 32비트 파이썬 3.11(pythonw)이고 Tech 는 pandas 2.x 가 필요해 64비트 venv(`%USERPROFILE%\.venvs\chart_screener`)에서 돈다.
그래서 뷰어가 Tech 를 **별도 프로세스로 돌리고(창 없이)** 결과 HTML 을 **iframe** 으로 보인다. Tech 저장소(`G:\내 드라이브\Claude\Tech`, GitHub lkh0797-lab/Tech)는 혼자서도 돈다.

## 뷰어(기업추적)
- 탭: `data-t="vocal"` 버튼 → `data-t="tech"` '차트 발굴'. `viewVocal` 코드는 남기고 탭만 뺀다.
- `viewTech`: 머리(기준일 · 생성 시각 · 상태 · '다시 계산' · '새 창으로') + iframe(`/tech/report`, 높이 = 화면 − 머리). 계산 중이면 5초마다 상태를 본다.
- 서버:
  - `/api/tech` — {running, phase, at, report(파일 이름 · 시각), log(마지막 몇 줄), error}
  - `/api/tech/run` — Tech 스캔을 백그라운드로(이미 돌면 그대로)
  - `/tech/report` — `Tech/output/scan_*.html` 가운데 가장 새것을 text/html 로
  - 자동: 평일 16:00(장 마감 15:45 뒤) 한 번 · 뷰어를 켰을 때 마지막 리포트가 오늘 장 마감 전 것이면 15분 뒤 한 번. `subprocess` + `CREATE_NO_WINDOW`(창이 안 보이게).
  - 예전 보컬 `_vocal_auto_loop`(매일 07:00) 시작을 끈다 — `/api/vocal` · `보컬.py` · 결과 파일 · 백테스트 도구는 그대로.
- 경로: Tech 폴더 = `CHART_SCREENER_DIR` 환경변수, 없으면 `기업추적/../../Tech`. 파이썬 = venv, 없으면 오류 문구(설치 방법).

## Tech
- `chart_screener/vocal.py` — 보컬 규칙(기업추적 `보컬.py` 눌림목 모드: 거래대금 150위 · 테마 점유율 2배 · 대장 = 테마 시작일부터 거래대금 1 · 2위 · 큰 상승 +30% · 눌림 −8~−35% 2~15봉 · 지지선 ±2% · 거래량 감소 · 재유입 1.5배 양봉)을 Tech 자료(전 종목 일봉 `ud.ohlcv`, 네이버 테마 `sector_map`)로 옮긴다. 전 시장 단면(순위 · 테마 점유율 · 대장 이력)을 한 번 세어 종목마다 깔때기 결과를 낸다(numpy 행렬).
- `patterns/vocal.py` — `@register("vocal", "보컬")`. `ctx.info["vocal"]`(scan 이 넣음)을 PatternResult 로: 단계 ④⑤ 형성 중 · ⑥ 피벗 근접 · ⑦ 돌파(손익비 1.5↑), 손절 = 눌림 저점, 목표 = 직전 고점, 근거 ✔/✘, 차트 표시(고점 · 눌림 저점 · 닿은 지지선 · 급등 최대봉 · 신호봉). `info` 가 없으면(analyze · backtest) '전 종목 scan 에서만'.
- 점수 · 매수 계획 · 실시간 감시에는 넣지 않는다 — 과거 검증(기업추적 `도구/보컬_백테스트.py`, 2013~2026 346건)에서 **승률 31% · 평균 −2.4% · 20일 초과수익 −4.8%p** 로 손실이었다. 후보 목록에는 올리고(칩), 대표 패턴이 없으면 표시용으로만 '보컬'.
- 칩 순서: … CAN SLIM · 포켓 피벗 · **보컬**.
- 테스트(합성 자료): 깔때기 단계 ④→⑦, 강한 테마 · 대장 판정, 정보 없을 때.
