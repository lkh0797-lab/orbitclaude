## 1. v3 점수 식 (고정 — 결과를 보고 바꾸지 않는다)

부분은 셋, 각 0~100, **그 날 잔고를 믿을 수 있는 회사끼리의 백분위**(높을수록 좋다).

| 부분 | 식 | 결측 |
|---|---|---|
| **수주** | 북투빌 백분위 · 잔고/연매출 배수 1년 변화 백분위의 평균(예전 '선행' 그대로) | 없으면 점수 없음 |
| **값** | 100 − PER 자기 역사 % 의 백분위(자기 과거보다 쌀수록 높다) | 50(적자 · 이력 짧음 · 풍경 없음) |
| **여지** | 흑자 회사끼리 4분기 합 영업이익률이 낮을수록 높은 백분위(예전 '전환' 그대로) | 50(4분기 적자 — `loss4`) |

점수 = (수주 + 값 + 여지) ÷ 3 − 10 × 위험 표지 수, 0 아래는 0. 같은 가중(⅓씩) — 가중을 고르지 않는다.

위험 표지(시점 t 까지 12개월, 정정 · 첨부 재제출 · 자회사 공시 뺀 원본, 서로 다른 날 수, `도구/공시분류.py classify` 범주):
- **희석**: CB발행 + BW발행 + EB발행 + 유상증자 + 제3자배정 ≥ 1
- **부실**: 회생절차 · 파산신청 · 감사의견비적정 · 관리종목_사유 · 관리종목_우려 · 실질심사 · 상폐우려 · 횡령배임 · 불성실_지정 · 자본잠식 · 보고서지연 · 투자주의환기 중 하나라도 ≥ 1

빠지는 것: **가격(반영 갭)** — 2020년 뒤 부호가 뒤집혔다(열로는 남긴다, 가치 척도 아님). **확인(수주 공시)** — 기간마다 부호가 바뀌고 금액 이력이 없다(펼친 행 · 계약 열에 정보로만). 예전 40일 `호재.BAD` 정규식 감점(기술적 매매정지도 '상장 위험'으로 −10 이 붙었다)은 위 위험 표지로 바꾼다.

단계(잠복 · 점화 · 반영 · 둔화 · 관찰) 규칙은 그대로 — 백테스트 비교가 끊기지 않게.

## 2. 검증 규칙 (미리 적음)

표본: `도구/시너지_백테스트.py` 패널(2013-06 ~ 2025-09 매달 말, reliable · 시점 뒤 정정값 아님 · 12개월 초과수익 있음). 위험 표지는 `--report` 때 공시 목록으로 시점마다 다시 센다(접수일 ≤ t). 값은 분기 패널 per_pct(접수일 ≤ t) — 예전 그대로.

- **주 지표 M1**: 둔화 뺀 행 안, v3 점수 날짜 안 분위 상⅓ − 하⅓(12개월 초과수익 중앙 차). 회사 재표본 90% 구간(`W.boot`)과 **해(年) 재표본** 90% 구간, ~2019 / 2020~.
- **믿음 표지(화면 문구를 정한다)**: M1 회사 구간 하한 > 0 **그리고** 해 구간 하한 > 0 **그리고** ~2019 > 0 **그리고** 2020~ > 0 이면 "근거 있음", 아니면 "근거 약함".
- 결과와 상관없이 화면 점수는 v3 로 바꾼다 — v2 는 둔화 뺀 안에서 2020년 뒤 무신호이고 순위를 가장 많이 움직이는 부분(가격)의 부호가 뒤집혔다는 것을 이 문서 전에 알았다. 결과는 믿음 표지와 문구만 정한다.
- 부: v3 − v2 짝 차(같은 행, 회사 구간) · IC(겹침 보정 t) · 전체 행 상⅓ − 하⅓ · 잠복만 2020~ · 위험 표지 있음 vs 없음(둔화 뺀, ~2019 / 2020~).
- 판정 말: "나았다 / 못했다 / 차이를 확신할 수 없다"(구간이 0을 벗어날 때만 앞 둘).

## 3. 점수 해석 1~2줄 (종목명을 누르면)

서버 `시너지.explain(r)` 이 만든다(시험 가능). 링크 대신 이름 아래에 펼친다. 회사 궤도로 가는 길은 줄 끝 작은 '궤도 →'로 남긴다.

1줄: `점수 N = 수주 a · 값 b · 여지 c [− 위험 10×k]` + 가장 센 부분의 실제 숫자(예: "들어온 수주가 매출의 2.3배 · 잔고 연매출 1.8년치(+0.6년)").
2줄: 가장 약한 부분 또는 빠진 부분의 실제 숫자 + 회사별 주의(4분기 적자 → 여지 50, PER 이력 없음 → 값 50, 위험 표지 이름과 날짜, 반영 단계).
