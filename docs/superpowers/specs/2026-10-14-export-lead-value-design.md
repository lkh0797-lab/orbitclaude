# 수출 선행 발굴 — 통관은 올랐는데 주가 · 값은 아직 (2026-10-14)

## 목적

수출 추적(관세청 통관, 분기보고서보다 1~2달 빠름)과 저평가(싸졌는데 가치는 지킴)를 잇는다.
**아직 공시 안 된 분기의 통관 수출이 뚜렷이 늘었는데, 주가는 따라오지 않았고, 값은 자기 역사 기준으로 싼 회사**를 먼저 찾는다.

사용자 결정(2026-10-14): 방향 1 — 수출 추적 탭 안에 새 칸 + 저평가 탭 줄에 배지. 독립 탭 아님.

이 프로젝트의 원칙 그대로:
- 검증 없는 점수는 팔지 않는다. **구현 전에 과거 검증을 먼저 돌리고**, 그 결과가 화면 제목을 정한다(발굴 / 관찰 — 과거 우위 근거 없음).
- 모르는 것은 **모름**으로. 영상 · 책의 일화 수익률은 쓰지 않는다.
- 새 DART · 관세청 · 네이버 호출 없음 — 모두 캐시 읽기. 새 자동 루프 없음.

솔직한 출발점: 기존 검증(수출추적.py 머리말)에서 분기 통관 증가율 ↔ 그 분기 매출 증가율 순위상관 0.37(t 12)이었지만, **90일 주가와는 0.04(t 1)로 뚜렷하지 않았다.** 수출만으로는 주가가 움직이지 않는다. 그래서 '주가는 아직 · 값은 싸다' 조건과 묶었을 때 다른지 재야 한다 — 그게 이 설계의 검증 질문이다.

## 1. 발굴 규칙

대상: `status == "ok"` · 등급 A 또는 B · `aligned.lumpy == False`(덩어리 수출 아님).

세 조건:

| # | 조건 | 판정 | 모름이 되는 때 |
|---|---|---|---|
| 1 | **수출 단서** | `aligned.reported == False`(지금 분기 = 아직 공시 안 된 분기, 통관 2개월↑) 이고 `aligned.cur ≥ +20` | `reported == True`(새 분기 통관이 1개월 이하) → 단서 아님(목록에서 빠짐). 등급 C → 빠짐 |
| 2 | **주가는 아직** | 최근 3개월 수익률 ≤ 같은 기간 전 종목 중앙값 **또는** 52주 고점 대비 ≤ −25% | 주가 이력 91일 미만 |
| 3 | **값은 싸다** | 풍경 `decide.pct ≤ 50`(PER 이 자기 역사 중앙값 이하) | 풍경 없음 · 적자(PER 없음) · PER 표본 8분기 미만 |

빨간불(하나라도 있으면 발굴 아님):
- 저평가 줄이 있으면 그 줄의 `red` 그대로(잔고 · 선수금 · 업종 수출물가 · 재고 순환 · 부채 200%↑).
- 저평가 줄이 없으면 풍경 `de ≥ 200`(금융업 제외 — `VAL_FIN`).
- 공시위험(작전주 꼴 · 상폐 절차 · 감사 · 자본잠식) · 증권사 상태(거래정지 · 관리 · 정리매매 · 투자위험) — `_val_apply_risk` 와 같은 규칙으로 '관찰' 강등.

등급:
- **발굴** = 1 · 2 · 3 모두 통과, 빨간불 없음.
- **관찰** = 1 통과, 2 또는 3 이 실패 · 모름, 또는 빨간불. `why` 에 이유를 전부 적는다("주가 3개월 +18% — 이미 올랐다", "PER 자기 역사 상위 72%", "값 모름 — 적자", "빨간불: 부채비율 240%").
- 1 실패 → 목록에 없음.

**벌어짐**(정렬 · 그림): `gap = 지난 12개월 통관 증가율(signals.y12) − 주가 1년 수익률(%)`. 같은 길이(12개월)끼리 비교한다. 둘 중 하나 없으면 None → 정렬 맨 뒤.

## 3. 과거 검증 — `도구/수출선행_백테스트.py` (구현 전에 먼저)

**시점**: 2021-02 ~ 가장 최근 통관 달, 매달 **16일** = 관세청이 지난달 치를 내는 15일께의 다음 날(공개가 15일을 넘기는 달도 있다 — 하루 늦게 봐도 손해 쪽). 진입 = 그 날 다음 거래일 종가(`억울_백테스트.next_day` 규칙).

**시점 자르기(미래 참조 금지)** — 한 회사, 시점 d(= 통관 달 m 의 다음 달 16일):
1. 통관: `series_long` 을 `≤ m` 으로 자른다.
2. 마지막 공시 분기: bt_panel 에서 그 회사의 접수일 `t ≤ d` 인 마지막 lab. 없으면 건너뜀.
3. 검증 쌍: 통관 분기 합(완성 분기만) ↔ bt_panel 의 `rev_yoy`(그 분기, 접수일 ≤ d). `수출추적._grade` 와 같은 규칙으로 **시점 등급**(쌍 6개↑, 상관 0.3↑, 통관/매출 비중 5~150%). 지금 등급은 쓰지 않는다 — 지금 등급으로 과거를 고르면 선택 편향.
4. `수출추적.aligned(mon_cut, last_rev_q_d, pairs_d)` → 조건 1.
5. 주가: `.cache/price` 로 3개월 수익률 · 전 종목 중앙값(같은 날짜 쌍) · 52주 고점 대비 → 조건 2.
6. 값: bt_panel 의 `per_pct`(접수일 ≤ d 인 마지막 줄) ≤ 50 → 조건 3. (지금 화면은 풍경 `decide.pct` — 둘 다 '자기 역사 PER 백분위', 같은 조건.)
7. 빨간불은 bt_panel 로 알 수 있는 것만(부채 — 저평가 백테스트 표본의 debt_eq). 공시위험 · 증권사 상태는 과거 시점을 모른다 → 쓰지 않고 한계에 적는다.

**통로 고정의 한계**: 통로(시군구 × HS)는 **지금** 보고서로 잡은 것이다. 2021년엔 공장이 달랐을 수 있다. 피할 수 없으니 문서 · 화면 각주에 적는다. 생존 편향(지금 상장사만)도 같다.

**재는 것** — `억울_백테스트.py` 와 같은 식:
- 3 · 6 · 12개월 수익률 − 같은 기간 전 종목 **중앙값**(초과수익, `grp_ret("__all__")`). 평균이 아니라 중앙값으로 비교 — 오른쪽 꼬리 때문에 평균끼리 · 중앙값끼리만 비교한다(업황 시계 교훈).
- 묶음: 발굴 / 관찰(단서는 맞음) / 단서만(2 · 3 무시) / 벌어짐 위⅓ vs 아래⅓(발굴 + 관찰 안에서) / 비교: 같은 날 통로 있는 회사 전체.
- 앞(2021~2023) · 뒤(2024~) 반, 회사 단위 부트스트랩 90% 구간, 신호 수 · 회사 수 · 신호 날 수.
- 겹침: 같은 회사가 연속 달에 또 걸리면 모두 센다(독립 아님) + "같은 회사 연속 신호 비율" 을 적는다.

**결정 규칙**(화면 제목):
- 발굴 묶음의 12개월 초과수익 중앙값이 앞 · 뒤 **모두 플러스**이고, 전체 구간이나 한쪽 반의 구간이 0 을 벗어나면 → 제목 "수출은 먼저 올랐다 — 주가 · 값은 아직 N곳", 등급 이름 '발굴'.
- 아니면 → 제목 "수출은 먼저 올랐다 — **관찰** (과거 우위 근거 없음) N곳", 등급 이름 '관찰 후보'. 목록 · 줄은 그대로.
- bt.json 이 없으면 → 제목에 "(검증 전)".

**출력** `.cache/수출선행/bt.json`: `{v, at, dates:[첫, 끝], n, groups:{발굴:{n, firms, days, ex3, ex6, ex12:{med, ci, early, late}}, …}, gap_split, overlap, verdict:"발굴"|"관찰", caveats:[…]}`. 실행 `python 도구/수출선행_백테스트.py` (주가 988곳 읽기 포함 10분 안팎 예상), `--report` 로 재출력.

## 4. 코드 자리

- **새 모듈 `수출선행.py`** — 순수 함수만, 서버 · 재무 import 없음:
  - `due_date(q) -> date`, `due_label(q, today) -> "D-n · 11-14까지"` (주말만 민다)
  - `hit_rate(pairs) -> (n_hit, n)`
  - `gap(y12, px_yoy) -> float|None`
  - `judge(inputs) -> {tier, why[], checks{clue, price, value, red}}` — inputs 는 평범한 dict(aligned · grade · lumpy · ret3m · univ3m · dd52 · per_pct · red[] · risk_tags[])
  - `pit_grade(pairs) -> "A"|"B"|"C"` (수출추적._grade 와 같은 문턱 — 그 함수를 import 하지 않고 문턱 상수를 공유: `수출추적.MIN_COVER/MAX_COVER` 는 import 해도 된다 — 그 모듈은 관세청 모듈만 부른다)
  - `index_series(mon, px_by_month, months=24) -> [{ym, x_idx, p_idx}]`
- **서버**: `exlead_view()` + `GET /api/exlead` — 재료 묶기 · 메모리 캐시(키 = 수출 결과 파일 mtime + 주가 기준일 + 풍경 판 수). 전 종목 3개월 중앙값은 하루 한 번(`_last_close` 날짜 키). 응답 `{at, basis(통관 기준월 줄 — 수출 추적 탭의 expBasis 와 같은 문구), rows[], bt, rules, caveats}`.
- **저평가**: `value_view()` 가 줄마다 `exl: {tier, cur, months_label, due, why[0]}` 을 붙인다(exlead 캐시에서 code 로). 계산은 한 군데.
- 서버 코드는 `# ---- 수출 선행 발굴 (2026-10-14)` 한 구역에.

## 5. 화면

- **수출 추적 탭** (`viewExport`): 단계 숫자 아래, '이익에 우호적' **위**에 새 칸 `expPick lead`.
  - 머리: 제목(3절 결정 규칙대로) · 부제 "통관은 올랐는데 주가 · 값은 아직 — 분기보고서 전에" · "과거엔 이랬다: 12개월 초과 중앙값 +x%p [a, b] · n건 · 앞 +x / 뒤 +y" · 토글 **'관찰까지 보기'**(기본 꺼짐 — 발굴만).
  - 카드: 기존 `expCard`(24개월 증가율 선) + 아래 줄들: 단서 · D-n · 적중 · 주가 · 값 · 벌어짐 · 등급 알약 · why(툴팁 + 관찰이면 한 줄 노출).
  - 벌어짐 그림: 카드 더블클릭 = 기존 '최근 5년' 대신 **수출 지수 vs 주가 지수** 로 바꾸지 않는다 — 기존 동작 유지. 벌어짐 그림은 카드 안 작은 두 번째 선(주가 지수)으로 겹쳐 그린다(색 다르게, 범례 한 줄).
  - 각주 한 줄: 통로 고정 · 생존 편향 · 매출 ≠ 이익 · 잠정실적.
- **저평가 탭** (`viewValue`): 줄 이름 옆 배지 `수출 단서 +35% (8월까지)`; 올리면 "2026Q3 아직 미공시 · 기한 11-14 · 통관 적중 7/9 · 등급 발굴". 저평가 등급 · 점수는 **안 바꾼다**(점수 항목 추가는 검증 뒤 별도).
- 궤도 · 풍경 · 다른 탭은 손대지 않는다.
