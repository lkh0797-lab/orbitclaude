# 시너지 발굴 1차 개선 — 자기 역사 PER 위치 · 과장 문구 정리 · 작은 결함 (2026-10-14)

## 배경 · 감사 결과(읽기 전용 감사 2026-10-14, 세 갈래 + 종합)

사용자 기준: **"지닌 가치 대비 저평가된 기업을 발굴하는 데 의미가 있어야 신뢰도가 있다."**

감사가 확인한 사실(숫자는 `.cache/시너지/bt_report.json` 10-07 · 패널 재집계 · `.cache/quarter/bt_panel.json` join):
- 지금 점수는 **수주 모멘텀 순위**다. 과거 12년에서 살아남은 건 둘 — 둔화(잔고 1년 감소) 회피(둔화−관찰 −5.6%p [−9.3, −2.5]) · 북투빌 높을수록(단조). 둘 다 가치 대비 가격이 아니다.
- **가치 대비 가격을 재는 항목이 없다.** 반영 갭은 증가율 차(둔화 뺀 2020년 뒤 IC −0.070), PER 은 점수 밖 · 접수일 주가 · 적자 None, 시총은 분모로 쓰이는 식이 없다. 점수 상위 20 중 자기 역사 PER 보다 싼 곳 2곳.
- 단계 넷(잠복 · 점화 · 반영 · 관찰)은 90% 구간이 전부 겹친다 — 구분 안 됨. 점화(rev_accel · margin_delta) · 반영(PER≥40) · 잠복(p1y<0.5·yoy) 조건은 무신호 변수.
- 전환 부분 `−max(m4, 0)` 이 영업적자 회사를 최상위 동률(90점)로 올린다 — "흑자 · 적자를 따지지 않는다" 문구와 반대. 상위 20 중 적자 10곳.
- 확인(15점)은 검증된 적 없고 없으면 0점(95/115), 창 40일, 원문 None 17건 영구 캐시.
- 자기 역사 PER 위치만 둔화 뺀 표본에서 앞/뒤 부호가 같고(IC +0.109 / +0.094) 상⅓−하⅓ 구간이 0을 벗어났다(+8.9 [+2.5, +15.5]). '싼 수주'(둔화 아님 · 북투빌 ≥ 1.1 · 잔고−매출 ≥ +15%p · PER 자기 역사 하위 50%) +10.7 [+4.0, +20.5], 이긴 68%, −30%↓ 4%, 한 달 3곳 — **표본 안 값**(앞 +3.2 / 뒤 +19.5, 각각 0 걸침).

사용자 결정(2026-10-14): 감사 추천안(안 1)으로 진행.

## 목적

1. 화면 · 문서가 사실만 말하게 한다(과장 20곳 정리).
2. '가치 대비 가격'을 재는 항목(자기 역사 PER 위치)을 시너지 행 · 추천필터 · 표 · 직접 설정 필터에 넣는다 — **점수 식의 가격 부분 교체는 아직 아님**(앞으로 기록(forward)으로 표본 밖 성적을 본 뒤).
3. 점수 식의 작은 결함을 고치고 **백테스트를 다시 돌려 새 숫자를 화면이 읽게** 한다(결과를 보고 문턱을 바꾸지 않는다 — 문턱은 이 문서에 먼저 적는다).
4. 매일 목록을 남겨(forward) 표본 밖 검증의 재료를 쌓는다.

원칙 그대로: 새 DART · KIS · 네이버 호출 없음(캐시만), 새 자동 루프 없음, 모르는 건 모름, 검증 안 된 건 '검증 전'.

## 2. 화면

- **추천필터**: '싼 수주' 카드를 맨 앞에. 설명 "둔화 아님 · 북투빌 1.1↑ · 잔고가 매출보다 15%p 빨리 늘고 · PER 이 자기 역사 중앙값 아래 — 잔고는 느는데 시장이 아직 안 믿는 자리". 과거 성적 줄은 다른 카드처럼 `bt.rec.cheap` 에서(값은 다시 돌린 백테스트가 정한다 — 하드코딩 금지).
- **직접 설정 필터**: `leadMin`(잔고−매출 %p) · `perPctMax`(PER 자기 역사 %) 칸. `synPass` · `rec_pass` 같은 키.
- **표 '가격·밸류' 묶음**: 'PER(접수일)' → **'PER'(오늘 주가, 풍경)** + **'PER 자기 역사 %'** + **'시총/잔고 업종 %'**. 툴팁에 창 설명 · "낮을수록 싸다 / 잔고에 비해 시총이 작다(사이클 지표, 등급 근거 아님)".
- **EXHIBIT 주목 종목**: '싼 수주' 통과 종목을 먼저(점수 순), 8곳이 안 차면 나머지는 점수 순 — 머리말 "TOP IDEAS · 싼 수주 먼저". 범례 · 색은 그대로, 각주 "단계는 과거 수익을 못 갈랐다".
